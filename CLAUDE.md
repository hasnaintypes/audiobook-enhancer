## Colab sync

- Any cell added, edited, or run in a Google Colab notebook via the colab-mcp tools must be mirrored as the same change to the matching `.ipynb` file in `notebooks/` in this repo, so the local file always reflects the live Colab notebook's content.

## Commit rules

- Always commit in small, modular commits — one logical change per commit, not a batch of unrelated changes.
- Never add a `Co-Authored-By` line (or any AI-attribution line) to commit messages in this repo.
